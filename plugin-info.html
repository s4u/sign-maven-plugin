Plugin Details

This report describes goals, parameters details, requirements and sample usage of this plugin.

Goals

Goals available for this plugin:

Goal Description
sign:help Display help information on sign-maven-plugin.
Call mvn sign:help -Ddetail=true -Dgoal=<goal-name> to display parameter details.
sign:sign
Deprecated. sign-maven-plugin is retired - please migrate to Apache Maven GPG Plugin, which provides the same features: signing by the Bouncy Castle Java library, configuration by environment variables and support for Maven 4. See Migration to maven-gpg-plugin.

Creates Open PGP / GPG signatures for all of the project's artifacts.

System Requirements

The following specifies the minimum requirements to run this Maven plugin:

Maven 3.6.0
JDK 1.8

Usage

You should specify the version in your project's plugin configuration:

<project>
  ...
  <build>
    <!-- To define the plugin version in your parent POM -->
    <pluginManagement>
      <plugins>
        <plugin>
          <groupId>org.simplify4u.plugins</groupId>
          <artifactId>sign-maven-plugin</artifactId>
          <version>1.2.0</version>
        </plugin>
        ...
      </plugins>
    </pluginManagement>
    <!-- To use the plugin goals in your POM or parent POM -->
    <plugins>
      <plugin>
        <groupId>org.simplify4u.plugins</groupId>
        <artifactId>sign-maven-plugin</artifactId>
      </plugin>
      ...
    </plugins>
  </build>
  ...
</project>

For more information, see "Guide to Configuring Plug-ins"
